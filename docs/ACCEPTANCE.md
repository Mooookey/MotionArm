本文与源代码、配置摘要、CSV 和视频共同构成提交材料。下列静态、动态及位移结果已填入 2026-11-04 的真实采集数据；用户已确认三个方向实体/模型同步与复位，视频录在另一设备，提交时仍须附原件，本工作区不含视频。**数据时长/链路完整不等于自动证明物理条件或位移准确；模拟演示不能作为硬件评测证据。**

## 1. 实现和设计取舍

硬件为 ESP32-D0WDQ6 与野火 MPU6050；I²C 地址 0x68，3V3 供电，SDA=GPIO21、SCL=GPIO22，总线 100kHz。无 OLED。ESP32 核心保持 3.3.12，复用现有 Adafruit MPU6050 初始化接口，不更新依赖。

数据链路：MPU6050 → 200Hz ESP32 定时采样 → 校准/低通/姿态与位移 → USB 串口 460800 → 本地 Web Serial → 曲线/三维模型/CSV。上传速率独立保持 115200。运行速率从原计划 230400 调整为 460800，以增加传输余量；完整性以各次真实记录的 CRC 与结束计数为准。

| 基本任务 | 实现 | 验收证据 |
|---|---|---|
| 六轴稳定读取 | 5ms 定时通知、checked burst、新样本标志、ESP32 64 位采样时间戳 | 六轴实时曲线、设备端间隔统计、CSV |
| 校准和滤波 | 静止约 3 秒陀螺零偏、一阶低通、Mahony、重力剔除与短时位移 | 参数摘要、原始/处理对比、四元数和位移 |
| 传输显示保存 | 逐采样 90 字节二进制帧、本地网页、完整 CSV/JSON | 源码、导出文件、网页截图 |
| 数据完整性 | 会话与序号、CRC、设备生成数、独立采样失败与队列计数 | END 摘要、接收统计、异常提示 |
| 统一测试分析 | 60 秒静态、5 分钟漂移/丢包、采样间隔、动态滤波响应 | 下列六类图、数据和计算 |
| 三维姿态与轴对齐 | 带 XYZ 标签模型、四步验证、30 秒连续跟随 | 同时包含实体和屏幕的视频 |

选择一阶低通是因为参数可解释、计算量小，能在限时环境中用真实动态动作验证平滑与延迟的取舍；选择本地 Web Serial 是为了沿用已经验证的 USB 连接并避免离线安装上位机依赖。相关参考见文末。

## 2. 参数、单位与算法

以记录对应的 META/JSON 为最终参数来源，下面列出本次静态记录实际参数。

| 参数 | 本次记录值/约定 |
|---|---|
| ESP32 采样频率 | 200Hz，名义周期 5000µs |
| 串口速率 | 运行 460800、8N1；上传 115200 |
| MPU6050 输出频率 | 1kHz；ESP32 每 5ms 读取最新样本 |
| 加速度量程与换算 | ±4g，8192 LSB/g，g=9.80665m/s² |
| 陀螺量程与换算 | ±500°/s，65.5 LSB/(°/s) |
| 硬件 DLPF / 软件低通 | 44Hz / 20Hz |
| 加速度模长比例 | κ=0.869825006，仅 processed 使用；方法 single_pose_norm_scale |
| 陀螺零偏 XYZ | [-5.51317501, 0.91133881, -0.10806219] °/s |
| 独立校准样本数 | 602；评测窗口内不重新校准 |
| Mahony 参数 | Kp=0.5，Ki=0；陀螺输入按实现转换为 rad/s |
| 四元数 | [w,x,y,z]，body→world，右手系、世界 Z 向上 |
| 欧拉角 | ZYX 顺序，Yaw/Pitch/Roll；屏幕角度单位 ° |
| 原始数据含义 | 芯片寄存器数据按量程换算；已受共同硬件 DLPF 影响，未进行软件扣偏/滤波 |

启动校准使用静止样本均值估计三轴陀螺零偏 b；校准失败时要求重新静置，不使用一段明显运动的数据作为零偏。静止判定以样本稳定性为主，加速度模长仅以 0.5g–1.5g 作合理性筛查。加速度保留重力，不把三轴静态均值全部扣成零。

同一段独立的启动校准数据还计算单姿态重力模长比例 `κ = g / ‖mean(raw a)‖`，仅对 processed 加速度乘 κ，保存 `accel_calibration_method=single_pose_norm_scale` 和 `accel_norm_scale`。raw 按固定寄存器量程换算，完全保留。该比例不能分离三轴 offset、各轴 gain、轴间误差或放置倾斜，不能替代六面标定；同姿态处理后重力模长接近 g 是归一化的预期结果，不能作为独立的精度证明。3 秒校准与后续 5 分钟评测必须分开，评测期间 κ 不更新。

一阶低通：`y[k] = y[k-1] + α·(x[k] − y[k-1])`，`α = 1 − exp(−2π·fc·dt)`。fc=20Hz、dt=0.005s 时 α≈0.4665；首次有效值用于初始化滤波器。陀螺处理链为 `raw → raw−b → low-pass`，加速度为 `raw → κ·raw → low-pass`。

姿态由陀螺短时积分并利用加速度重力方向修正倾斜，四元数每次归一化。没有磁力计，Yaw 相对启动方向定义，不能得到长期稳定的绝对航向。欧拉角在 Pitch≈±90° 时存在表达奇异性，轴向验证以物理轴、角速度方向和四元数模型为准。

位移：`a_world = R(q)·a_body − [0,0,g]`，按实际 dt 梯形积分得到速度和位置。仅演示短时相对移动。静止零速约束会将速度置零而保留位置；归零按钮显式重置位移。匀速运动与静止不能仅靠理想加速度/陀螺可靠区分，因而此方法依赖“起止静止”的演示假设，不构成长期精确定位。

## 3. 测试条件与统计口径

统一测试目标为校准后水平固定、物理 +Z 向上，在同一位置连续静止至少 5 分钟，前 60 秒用于静态误差和波动。本次按人工“近似水平”静置条件采集；无独立水平仪/姿态参考，不能宣称完全满足理想水平条件。校准后另开新会话，评测期间未重新校准或归零。

当前人工放置若仅为“近似水平”，必须在结果说明中记录这一条件：倾斜会使 X/Y 出现重力投影，也会改变 Z 参考分量。与理想 [0,0,g] 的差值是本次放置条件下的误差，不能全部解释为加速度计固有偏置；严格对比需用水平仪或固定夹具复测。

本次会话 ID 为 2920458151，采集脚本时间为 2026-11-04 20:07:38（+08:00），设备首末时间戳为 280690872/585685872µs；共 61000 帧，时间跨度 304.995 秒、名义覆盖 305 秒。前 60 秒 12000 帧；角速度漂移取前 300 秒，实际积分 300 秒。设备与接收计数均完整，无采样失败、缺帧或长间断。

仍须保留物理条件限制：前 60 秒 raw ay 均值为 −4.098074m/s²，不能视作理想零参考附近的水平放置；全段 raw gx 峰峰值约 21.022901°/s，存在瞬态波动。数据完整性通过不自动证明记录期间完全无振动/运动，精密静态误差应使用可靠水平固定条件复测。

每条数据使用 ESP32 的读数开始时间 t_us。所有截图横轴以该时间戳构造，并注明单位。网页接收时间只用于“多久没有新数据”的提示，不用于采样率、滤波或漂移积分。

设备 START 确认会话开始；STOP 停止生成、排空发送队列后返回 END。丢包率分母来自 END.generated，接收端按会话过滤、CRC 检查和序号去重。缺少 END 时丢包率未知；不能用已收到的首尾序号替代设备总数。

统计完整窗口时允许最后一个名义采样周期计入时间覆盖，因此理想 60000 帧覆盖约 300 秒，而首尾采样时间戳跨度约 299.995 秒；漂移结果注明实际积分秒数。设备时间间隔统计优先采用 END，电脑端只对连续序号计算间隔，接收缺帧单列。

如出现失读、无新样本、错过采样周期、缺帧、队列丢弃或超过 20ms 的积分间断，该次数据仍保留分析，但不标记为完整的五分钟漂移测试。修复原因后重测，保留异常事实。

### 4.1 测量误差：同一段前 60 秒数据

## 5. 三维姿态与轴对齐视频

固定初始视角，视频同时拍到模块 XYZ 丝印/物理方向和网页模型。每次动作前回到相同初始姿态，不用接近 90° 时的 Euler 分量跳变作为坐标交换依据。

当前状态：用户已确认三个方向实体/模型同步、动作后复位一致，并确认视频录制在另一设备。工作区未收到视频文件，正式提交必须附该设备上的原件；不把用户确认或传感器数据冒称本系统自动物理核验。

1. 水平放置、+Z 向上，确认模型姿态与实体一致，模型 XYZ 标签清晰可见。
2. 右手拇指指向物理 +X，其余手指弯曲方向为正转，转约 90°；确认模型绕对应 X 轴同向转动，主要角速度 gx 符号一致。
3. 回初始姿态，按同样规则绕 +Y 转约 90°，确认 Y 轴及 gy。
4. 回初始姿态，按同样规则绕 +Z 转约 90°，确认 Z 轴及 gz。

随后连续、平稳地组合转动至少 30 秒，确认模型跟随，没有持续轴交换、镜像或反向。记录测试视频文件名及观察结果。偏航是相对值，不能把视频短时对齐视为绝对航向精度证明。

推荐保留第二轮 23–66.75 秒（seq4600–13350）的 43.75 秒连续记录，包含 X/Y/Z 及组合动作，不删除中间混轴内容：[连续展示选段](../results/selections/continuous_pose.json)。69.655–73.815 秒仅 4.16 秒短静止：[短静止选段](../results/selections/short_rest.json)，不能替代 60 秒或 5 分钟静态试验。

### 位移实物尝试及失败边界

另一个会话 3930646079 共 4517 帧、22.58 秒，200Hz、全收且 CRC0：[完整记录](../results/displacement_20261104/recording.json)、[CSV](../results/displacement_20261104/data.csv)、[报告](../results/displacement_20261104/report.html)。用户按约15cm往返指令操作，该距离不是独立尺量基准，不能据此给出正式百分比定位精度。

选用 6.325–10.070 秒（seq1265–2014）的起止静止尝试：[选段](../results/selections/displacement_attempt.json)。前6.325–6.675秒及后9.865–10.070秒静止标志均100%，段内最大四元数变化约3.91°；位置增量仍为 [0.077931,0.083819,0.568077]m，模长约0.579491m。全会话首末位置差模长约3.502017m，末位置 [0.969496,1.741560,2.880592]m。该结果明显存在量值漂移，**不能宣称15cm往返准确达标**。

失准不能全部归为人的操作问题。运动时姿态误差、重力剔除残差、单姿态加速度标定局限及二次积分均会放大位移；静止标志/ZUPT不能恢复已经累计的位置误差，也不能证明运动中的速度估计正确。本项目已实现并真实展示位移计算，但位移准确性仍是明确未解决的问题。

## 6. 仍存在的问题及具体拓展

当前边界：单次静态扣偏不能补偿全部温漂；硬件与软件滤波存在延迟；六轴 Yaw 无绝对参考；姿态误差及加速度残余会在二次积分中放大；零速约束依赖运动场景。报告应结合本次真实数据说明这些现象，不能用算法名称替代验证。

进一步方向：用现有 ESP32+MPU6050 制作**设备搬运倾倒与冲击记录器**。在当前采集链路上增加倾角/角速度/加速度阈值与持续时间状态机，在异常发生时保存前后各数秒的数据，并通过电脑显示事件时刻和等级。相比当前连续展示，它能把海量曲线变为“何时发生倾倒或冲击、持续多久、峰值多大”的事件记录；后续可扩展 ESP32 本地缓冲与无线取回。阈值需通过正常搬运、缓慢放置、突然翻倒等动作采集标定，不能直接将任意阈值当成可靠判据。
