# 不记轴名的实体动作说明

先把有芯片和 XYZ 箭头的一面朝上，那排接线脚朝向自己。
此时板面标注的 X 向右、Y 远离自己、Z 向上。下面所有动作都从这个姿态开始。

| 验证 | 具体动作 | 观察 |
|---|---|---|
| 初始姿态 | 平放静止5秒 | 模型稳定；初始欧拉角不保证恰好为零 |
| X 正向 | 靠近自己的接线边作为铰链，抬起远端，接近竖直后芯片面朝自己；保持3秒再放回 | 模型同步抬起、复位，主要为Roll变化 |
| Y 正向 | 右边作为铰链，抬起左边，接近竖直后芯片面朝右；保持3秒再放回 | 模型同步左侧抬起、复位；近竖直时欧拉角可能耦合 |
| Z 正向 | 始终保持水平，从正上方看逆时针转90度，接线边由靠近自己转到右侧；保持3秒，再顺时针复位 | 模型水平同步转向、复位，主要为Yaw变化 |

随后连续缓慢组合转动至少30秒；建议40秒，覆盖阅读提示和动作切换。
验收视频应同时展示实体模块和网页模型。上述动作的方向按板子丝印判断，
不按观察者对屏幕上“顺时针”的直觉交换轴。

位移单独开一段记录：停止上一段并导出JSON，平放静止后点位移/速度归零，
开始记录，保持板面水平向右平移约10–20cm、静止2秒，再移回并静止。
这是短时相对位移演示；积分数值会受姿态误差、加速度误差和零速判定影响，
不能将其作为尺量距离或长期定位结果。

本次人工交互中，操作者已分别反馈X、Y、Z三个动作的模型同步抬起/转向并复位。
这属于人工观察记录；数据与视频仍需各自保留，不能以这段文字替代实体视频。
