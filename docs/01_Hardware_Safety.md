# 01｜硬件接线、供电、标定与物理安全

> 本文中“已记录”指上传资料的记录，并不等于本次已通电实测。任何电压、引脚、电流、脉宽与机械行程均须在实际装置上复核。

## 1. 两块 ESP32 的职责与引脚表

**角色原则：** 严格按连接在板上的模块定义 `wearable`（MPU6050 + 两按钮）与 `robot`（PCA9685 + 伺服控制 + USB PC），而非依据“第一/第二块板”编号。`AGENTS.md` 称按钮 GPIO25/26 位于第二块 ESP32；照片无法完全证明 MPU6050 是否与两个按钮位于同一块板。若并非同板，先改线使之满足上述两个角色，或者在修改设计后同步更新所有协议/固件文档。切忌直接将固件烧录到猜测的串口。

### 1.1 `wearable` ESP32

| 设备 | ESP32 引脚 | 电气/操作要求 |
| --- | --- | --- |
| MPU6050 VCC | 3V3 | 3.3 V 供电，不接外置伺服 V+ |
| MPU6050 GND | GND | 与腕端 ESP32 GND 相连 |
| MPU6050 SDA | GPIO21 | I²C SDA，首次扫描建议 100 kHz |
| MPU6050 SCL | GPIO22 | I²C SCL |
| 按钮 A OUT | GPIO25 | 模块低电平表示按下；作为 `deadman`，持续按住才有新的移动目标 |
| 按钮 B OUT | GPIO26 | 模块低电平表示按下；短按夹爪、长按模式 |
| 按钮模块正极 | 3V3 | 以实际模块允许电压为准 |
| 按钮模块负极 | GND | 与同板 ESP32 共地 |

IMU 预期地址 `0x68`，`WHO_AM_I=0x68`。有些 MPU6050 模块板自带上拉、电平转换和稳压，外观相似却不同；目前配置按已有 3V3 接线使用，不随意给原始芯片施加 5 V。按钮是**有源三引脚模块**，不能只照搬两脚机械按钮的 `INPUT_PULLUP` 接线图；必须先读静态/按下电平，确认实际模块没有浮空或反相行为。使用 GPIO25、GPIO26 不占用启动模式相关的常见 strap 引脚。

### 1.2 `robot` ESP32 与 PCA9685

| robot 引脚 | PCA9685 | 说明 |
| --- | --- | --- |
| 3V3 | VCC | 仅逻辑供电，I²C 上拉逻辑电平匹配 |
| GND | GND | 驱动板逻辑地，同时须与伺服外置电源负极连通 |
| GPIO21 | SDA | I²C |
| GPIO22 | SCL | I²C |
| 可选 GPIO27 | OE | **只有确认模块允许访问 OE 并正确增加默认禁能电阻后才使用**；高电平禁能 PWM |
| USB CH340 | 电脑 USB | FastAPI/PySerial 与设备握手通信 |

**实际四路映射（不可照搬网上 CH0–CH4 示例）：**

| 逻辑顺序与 ID | 关节 | PWM 通道 | 硬件名称（AGENTS） | 特别约束 |
| --- | --- | --- | --- | --- |
| `0: base` | 底座旋转 | **CH14** | 底座 | 避免缠线、触碰支架 |
| `1: shoulder` | 肩部俯仰 | **CH15** | 大臂 | 最主要承重，下垂风险最高 |
| `2: elbow` | 肘部俯仰 | **CH13** | 小臂 | 上下臂可能互相干涉 |
| `3: gripper` | 夹爪 | **CH12** | 夹爪 | 绝不持续命令夹爪压向机械止挡 |

建议在照片上贴纸标记 `CH12~CH15` 的 3 针插头方向：信号/SIG、V+、GND。插错方向能造成设备损坏。每个 `arm_id` 与 PCA9685 通道要固定在单一配置表；后端/前端不使用自行重排的通道号。

## 2. 供电电路和热/电流预算

### 2.1 绝对规则

- **绝不**由 ESP32 的 3V3 引脚、USB 5V 引脚或 PCA9685 的 VCC 引脚向四台舵机提供动力电源。
- 外置稳压伺服电源正极接 PCA9685 伺服电源端子 `V+`，负极接电源 `GND`；机器人 ESP32 的 GND 与伺服地必须共地，逻辑 VCC 只接 3V3。
- 先断电测电阻和极性；上电用万用表验证逻辑 VCC、舵机 V+、GND，不用 PCB 丝印颜色猜测。
- 电源应有可触达的**实体断电开关/总开关**和适配的保险丝/限流功能，并配置足够规格的主干线与端子。若 PCA9685 端子不能承载合计电流，应使用额定匹配的独立电源分配端子排，而不是强行走细针排。
- `OE` 高电平只能关闭 PWM，**不能切断 V+、不能保证机械臂保持原位，也不能消除电源短路风险**。软件“急停”与物理电源断开不可互相替代。
- **PCA9685 独立产生 PWM：** 即使 robot ESP32 死机/复位，它也可能继续输出上一个已设定的 PWM；只有 robot 正常运行时软件 watchdog 才能可靠更新输出。若能修改硬件，可评估独立硬件看门狗 + OE 上拉默认禁能方案，但关闭 OE 会让重力关节失去保持力矩，必须先完成机械支撑设计。MVP 必须保留可触及的伺服电源实体断电手段。

### 2.2 功率评估方法

上传资料写“996 数字舵机”，未包含可确认的品牌和具体型号。可参考原厂 TowerPro MG996R **标称** 4.8–6.6 V、单台 stall 电流约 1.4 A，但仿品和不同批次可能不同；以上只能用作**规格核对示例**，不是当前实物实测值。四台同时触及类似堵转电流可达到约 `4 × 1.4 A = 5.6 A`，还未计导线压降、启动冲击和余量。因此，不能认为仅因为某开源项目写“5V/2A”就适合你们的四舵机机械臂。

采购/选用电源以 **具体舵机铭牌 + 四路同时启动实测电流 + 电源瞬态表现**为准。对于经确认可工作在 5–6 V、峰值接近上述量级的四舵机装置，**5–6 V、额定电流约 8–10 A 的合规稳压电源**可作为待核对候选，而不是已确定采购值；电源额定电流高并不替代保险丝、线路容量、过流保护和温升监测。禁止盲目把电压调到超出实物舵机额定范围。

PCA9685 板上常见的大电解电容可缓解短暂供电波动，**不能替代足够的电源功率**。照片能看到电容，但不能仅凭照片确定其接线功能、耐压余量或健康情况。外置电源回路的地线与 USB 电脑之间不能形成不明确的反灌路径。

### 2.3 物理急停与重力风险

1. 测试前固定底座，并用可承受机械臂重量的挡块/托架支撑肩肘。确认即使切断伺服电源，也不会砸桌面、压手或把夹取物甩出。
2. 物理急停：**切断伺服电源**；可另用软件 `STOP` 作为普通停止。执行急停后机械臂的实际角度未知，系统必须进入 `SAFE_BOOT/ESTOP_LATCHED`，重新人工检查后才可解锁。
3. 不允许在夹爪悬空持物时为了“节能”自动释放肩/肘 PWM；断电时夹爪和承重关节会有不可控的重力后果。
4. 准备地面/桌面缓冲垫和低质量泡沫物块；手指、衣物、数据线及旁观人员不能位于夹持区和关节扫掠区。
5. 发现舵机抖动持续扩大、齿轮尖叫、异常发热、供电线温升、ESP32 频繁复位，**停止实验并物理断电**。不要在异常状态运行自动 Home。

## 3. 初次上电 / 第一次舵机校准 SOP

**先做掉电检查，不要运行现成仓库的“全部设 90° 并移动到 Home”示例。** 当前普通三线舵机无外部轴角反馈，软件中的 `90°` 和机械当前真实角度没有可验证对应关系；某些开源工程在通电时立即初始化 Home，这对装好的承重臂危险。

1. 拍摄所有接线近照，记录供电电压、实际 USB COM、两板 MAC、板卡角色、舵机插头方向；确认 `AGENTS` 通道表与实物一致。
2. 断开四路动力电源，用 I²C 扫描器分别确认 wearable 的 0x68 与 robot 的 PCA9685 通常地址 0x40。无法找到设备时先处理接线，不要启动 PWM。
3. 以**拆下连杆/卸载舵盘或限制负载的夹具方式**隔离一个舵机，先以经确认安全的中间脉宽尝试极小变化；这里的“安全脉宽”也必须按当前舵机规格选定，绝不设定全系列通用硬编码范围。
4. 每次只测试一路，记录脉宽变化 10–20 µs 级别时的旋转方向；确认不会触到机构硬限位才逐步扩展，靠近端点时缩小步进并保留安全余量。
5. 对每路记录 `min_us`、`max_us`、`home_us`、`inverted`、`logical_min_deg`、`logical_max_deg`、`max_velocity_deg_s`、`max_acceleration_deg_s2`；夹爪另记 `open_us`、`close_us`、`max_closed_hold_ms`，并用泡沫块验证“能抓住但不顶死”。
6. 按负载由小到大的顺序装配/测试。肩、肘一次仅允许很小角度变化，托住承重结构，观察是否会击打底座、相互干涉、下垂或电源掉压。
7. 测定一个**外力支撑下可安全确认的 `initial_pose`**，拍摄见证照片并记录肉眼基准标记。沿实际允许工作区逐点验证肩/肘联合姿态、底座扫掠线与桌面是否碰撞，标记禁止的关节组合或严格约束允许工作区；未完成确认不得启用回放、Home、联动。
8. 在实测完成后填 `config/robot_calibration.json`、计算版本哈希，并固化到机器人固件及后端。**任何未填项为 null 的配置不得 ARM**。
9. 启动后人工核对实际机构与指定初态匹配；若不匹配，不可以使用上一次保存的 `q_applied` 作为真实角度。

### 3.1 角度、脉宽和量纲

PCA9685 为 12 位 PWM 生成器。假设输出频率以 50 Hz 开始测试，周期 `T ≈ 20,000 µs`，一个计数约 `T/4096 ≈ 4.88 µs`（实际晶振误差与驱动函数实现可能造成偏差），舵机的可用脉宽需要逐台标定。

采用“**统一逻辑角度**→各舵机实测脉宽映射”的方式。

```text
u = clamp((logical_deg - logical_min_deg) / (logical_max_deg - logical_min_deg), 0, 1)
if inverted: u = 1 - u
pulse_us = min_us + u * (max_us - min_us)
```

注意逻辑 `0°` 是本项目的约定，不要求等于舵机内部真正机械 `0°`。脉宽上限应留出机械安全余量，不能为了增加行程让机械臂硬顶止挡。需将当前安装结构的 `shoulder`、`elbow` 逻辑方向确认为一致的正方向。

### 3.2 `Home` 及初始姿态规则

`Home` 是**经实物验收的安全目标姿态**，不是固件写死的 `[90,90,90,90]`。首次上电时若无外部位置传感器，执行端不得宣布真实位置是 Home。系统只能报告 `position_known=false`，在工作人员按标记手动检查、支撑机械臂并完成安全初始化流程后，才记录可执行的 `assumed_initial_pose`，同时在 UI 显示“**人工确认/非编码器测量**”。

不要设计“上电自动缓慢地从未知位置移动到 Home”：慢速也可能撞机，尤其肩/肘运动方向尚未知时。若需要自动返回 Home，必须先在实验中证明从允许的所有初始安全姿态都存在安全路径；否则仅允许特定固定初态下人工点按确认执行。

## 4. 夹爪保护策略

夹爪靠伺服脉宽压合，没有压力/电流反馈。采用“**位置软限幅 + 动作次数/驻留计时 + 轻载对象 + 人工观察**”方式，不能声称具备堵转电流闭环。

- 夹爪从 `open` 向 `close` 移动时使用更低速度、小步进；先在无物体条件下找出不会顶死的闭合极限，再针对泡沫块适当留压缩余量。
- `gripper` 短按产生**边沿触发的切换事件**，长按绝不执行夹爪短按事件。松开 A 后不继续接受夹爪新动作。
- 记录夹爪达到闭合目标的时间；设置保守保持上限，超时报警并停止继续执行下一段搬运动作。**不能因为计时超时直接空中开爪，也不能因为节能直接切断肩/肘力矩**；应在演示设计中把对象先放到安全面上，或请求人工干预。
- 若所有可用闭合脉宽均不能保证足够摩擦，使用更轻的泡沫块或增加软垫，不继续提高闭合角度/堵转力。
- 试运行时每次抓取结束检测伺服温度（不接触带电运动件），如有明显温升或异味，立即停止并检查。

## 5. 安全条件的跨端分工

| 条件/措施 | wearable | robot ESP32 | 后端 | Vue |
| --- | --- | --- | --- | --- |
| 姿态有效性 | 主判定 + valid | 二次检查 | 记录异常 | 告警 |
| deadman | 发送状态 | 强制门控、丢失超时 | 显示 | 显示 |
| 关节限位与速度 | 不拥有最终决定权 | **最终强制执行** | 预检/冗余限制 | 输入范围提示 |
| 夹爪保持风险 | 产生离散按键事件 | 最大目标、节拍、时间保护 | 报警/停任务 | 人工处置提示 |
| 电源危险、下垂 | 无法处理 | 仅能报告/尽力降低风险 | 禁止任务 | 显示实体急停提示 |
| 控制权 | 请求 TELEOP | **唯一仲裁者** | 租约请求者 | 显示 owner |
| 上电真实关节位置 | 未知 | `position_known=false` | 需要人工确认 | 不得绘成“实测角度” |
