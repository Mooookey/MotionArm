# 06｜测试计划、故障注入、验收标准与报告模板

> 所有数值门槛标注为**设计建议**，必须在真实硬件上逐项验证、必要时降低速度或提高保护等级。当前没有现场通电、温升、波形、误差或抓放成功率实测结果。不得把本测试文档视为已通过报告。

## 1. 安全优先级与测试执行次序

依次按照 **无电源静态检查 → 单板无舵机模拟 → 单个拆卸舵机 → 托臂空载 → 机械臂空载 → 轻载泡沫 → 固定工位录制 → 固定工位回放**。任何阶段失败都回退到上一阶段，不可使用软件限位替代物理支撑。

**启动前硬门槛：**

- 有可接触的外置伺服电源总开关，电气极性/电压/地线连接经人工检查，机械臂底座已固定。
- 负载关节有安全支撑，手指、导线、桌面障碍不在扫掠区；只使用泡沫等轻质、低风险物体。
- `robot_calibration.json` 四个关节均经实物标定，且当前设备与固件读取校准哈希一致；未标定阶段仅允许隔离单舵机测试模式。
- 上电真实姿态已按机械标记人工核对，控制器不能自动以软件历史值作为实测轴角。
- 若出现热、烟、异响、持续堵转、供电线异常、反复重启，立即**实体断电**并保障关节重力支撑，测试判失败。

## 3. 可量化测量方法

### 3.1 失效到控制目标停止的响应

可在机器人端记录：`t_last_accepted_wearable_ms`、`t_deadman_release_detected_ms`、`t_watchdog_trigger_ms`、`t_q_target_stops_changing_ms`；用机器人自己的时钟算响应。对于无线断开试验，预期控制目标在**本机 watchdog 触发后**不再继续增加；推荐初始阈值为 250ms，需核查任务节拍实际是否满足。

由于没有外部轴角传感器，不能仅用 `q_target` 曲线计算“机械臂完全停止”的物理时长。如需物理停机量化，只能另加人工现场计时/外部仪器检测（不接入在线控制闭环），且在报告中区别两种指标。

### 3.2 滤波与死区

执行静止 60s 测试，观察 `roll/pitch` 标准差、峰峰值、偏移趋势、控制目标累计变化；还应测试佩戴固定/松动对姿态的影响。死区先从 5° 测，不达标则调整滤波或固定方式，而不是一味增大死区导致控制迟钝。`roll/pitch` 与伺服轴正方向的关系须记录为具体 `axis_sign` 配置。

### 3.3 无线与串口负载

无线统计：`received_unique / sent_unique`、每分钟最大连续缺帧数量、回调队列溢出数、错误帧数、重复事件数；Serial 统计：状态帧率、ACK 超时次数、JSON 无效数、后端进程 CPU 使用率。不要将 ESP-NOW `send success` 当作“舵机执行成功”；需要 robot 的应用状态/ACK 来证明接纳。

### 3.4 抓放成功定义

仅当同一轮操作满足“夹住泡沫块 → 离开 A 点 → 移至 B 点 → 正常释放 → 机械臂退出且物块留在 B 区”才记一次**成功**。抓起后掉落、未离开 A、放错 B、仅空摆均记失败。由于不做视觉识别，成功/失败由监护人员肉眼判定并录入，不由程序自动生成。

### 3.5 时间序列复现误差

计算软件跟踪误差 `e_q(t)=q_out_replay(t)-q_recorded(t)`（插值到相同时间轴），报告每关节 MAE / max_abs_error；它反映**控制命令执行链**一致性，不能称为实体位置精度。实体轨迹误差在没有编码器/视觉的情况下**不可测**，只可通过目标位置标记和人工观察定性评价。

## 4. 故障注入注意事项

**允许安全注入：** 软件模拟丢帧、反序帧、串口长度错误、拒绝控制权、FakeClock 看门狗超时；机械臂托住且无负载时关闭无线发射、关闭后端/拔 USB。对于伺服断电情景，必须先加重力支撑与缓冲垫。

**禁止危险注入：** 故意让伺服短路/反接、电源超压、带负载硬顶止挡、强行拔掉承重舵机动力让机械臂自由下落、用手阻挡高速运动的夹爪。这些并非必要测试手段。

## 5. 预检报告必须包含

```json
{
  "record_id":"example-id",
  "ok":false,
  "calibration_compatible":false,
  "first_q_within_tolerance":true,
  "record_complete":true,
  "speed_limits_ok":true,
  "gripper_hold_time_ok":true,
  "operator_workcell_confirmed":false,
  "violations":["CALIBRATION_MISMATCH","WORKCELL_NOT_CONFIRMED"],
  "warnings":["JOINT_POSITION_NOT_EXTERNALLY_MEASURED"],
  "may_start":false
}
```

实际程序需用稳定字段枚举，前端不能只依据单个 `ok` 字段就忽略 `violations`。

## 8. 发布 Gate

**Gate 0（可通电）：** H01/H02 + 安全支撑与物理断电。

**Gate 1（可开始 IMU 驱动）：** H03/H04/H05、I01–I04 完成，且无超限和机械损伤风险。

**Gate 2（可录制）：** W01–W03、C01–C04、P01–P03、F01–F02 完成，断线与 STOP 可靠。

**Gate 3（可回放）：** R01–R03 与 PC REPLAY 模拟通过，初始姿态明确。

**Gate 4（可展示）：** R04/R05/A01/A02 完成；轻载重复成功率达到课程目标或如实记录未达标并只演示已通过的子能力。
