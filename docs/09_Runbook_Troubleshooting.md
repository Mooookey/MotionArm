# 09｜现场运行手册、演示流程与故障排查

> 适用于完成 M0–M9 全部必要验收后的受监护固定工位演示。尚未通过硬件 Gate 时只可执行本手册的**掉电检查**与单板诊断，禁止直接照此运行带负载回放。

## 1. 每次演示前的掉电检查

1. 检查机械臂底座稳固、桌面无障碍/无人员手指在轨迹区，泡沫块 A/B 标记没有移动；准备承重关节的物理支撑和缓冲垫。
2. 确认外置伺服电源开关 OFF、额定电压与当前四舵机/驱动板相符、正负极正确、接线无裸露/松动；逻辑 VCC 与伺服 V+ 没有短接，公共 GND 连通。
3. 确认四个 PWM 插头在 CH14 底座、CH15 大臂、CH13 小臂、CH12 夹爪，线序与标定一致；MPU6050 在 wrist ESP32 GPIO21/22，按钮 A/B 是 GPIO25/26 且低有效。
4. 把腕端传感器固定到手腕背面，避免操作过程松动；确认电脑串口 CH340、Arduino 串口监视器已关闭、不要同时启动多个 FastAPI/串口调试工具。
5. 查阅当前 `calibration_id`、上一轮通过的测试记录和使用的示教 `record_id`；更换过螺丝/连杆/舵盘、电源电压或夹爪垫片，应重新验证标定，不直接使用旧录制。
6. 确保有一人监护机械臂，一人操作；单人时应降低动作复杂度，并让实体断电开关始终可触及。

## 2. 通电与系统启动

**严格顺序：**

1. 先让机械臂在支撑状态下处于预定的已标定**可确认起始姿态**，空载放置，按机械标记人工目视核对。
2. 给 ESP32 控制逻辑供电，验证串口报告 `SAFE_BOOT`、角色/协议/校准哈希、PCA/IMU I²C 探测成功；即使 ESP32 已通电，也不应默认认为舵机真实角度等于 Home。
3. 根据机构与电源开关布局，在人员远离夹持区且有支撑时接入合规伺服电源；如果固件没经验证能在默认上电阶段保持 PWM 禁能，只能按照已批准的单关节上电程序调试，不可以直接全系统 ARM。
4. 电脑启动 FastAPI 后，观察 `/api/status`：`robot_online`、`wearable_online`、`calibration_compatible`、`position_known_externally=false`；后端提示当前 `boot_id/session_id` 与配置是否一致。
5. 打开 Vue3 控制台，确保 Roll/Pitch 能随手腕改变、deadman 显示正确、四个关节软件目标与通信状态更新。页面显示“非实际轴角测量”。
6. 人工确认可安全 ARM 的关节姿态与桌面净空，确认之后由后端向机器人请求 TELEOP 授权；只有成功 ACK 且操作者按住 A 才能通过手腕新增移动目标。
7. 在真正夹取前，先做一次低幅 Roll/Pitch、两种模式和松开按钮停止的**空载预演**，确认异常行为能停止。

## 3. 标准演示脚本（固定 A/B 工位）

**阶段 A｜演示感知**：让操作员展示手腕 Roll 与 Pitch 两个方向的实时曲线、模式与按钮；不抓物，释放 A，展示软件目标停止新增位移与底层保留受限姿态。

**阶段 B｜演示遥操作**：人工确认 A/B 工位后，用手腕微倾控制底座；模式 SHOULDER / ELBOW 分别控制高度/距离，用夹爪短按闭合泡沫块；执行慢速搬运，移动到 B 并释放。此时页面持续显示的是关节软件目标，抓取成功由现场人工确认。

**阶段 C｜示教录制**：将泡沫块恢复 A、机械臂恢复已批准的起点，确认录制起始位置；点击“开始录制”，通过同样手腕动作完成一次搬运；点击“结束并保存”，展示生成的 recording ID、时长、帧数与夹爪事件，以及没有丢失/中断的状态。

**阶段 D｜轨迹回放**：将泡沫块放回 A；**不依靠脚本自动移动机械臂到未知 Home**，先人工确认机械臂初态与记录相符。选择录制→运行 preflight→人工逐项确认工作区、夹持范围、固定起点→开始回放。结束后人工确认泡沫块是否在 B，并在实验表里记录 `success/failure/unknown`。

**阶段 E｜停止与归档**：松开 wearable 的 A，结束录制或停止回放，释放控制权；等机械臂在安全支撑位置，按规范断开伺服电源。导出本次轨迹和实验记录，保留原始时间戳、固件/校准版本。

**禁止演示中临时改变位置：** 如果观众移动了泡沫块起点，当前系统没有视觉/物体检测闭环，**不具备自动寻找新位置**能力。须重新放回固定 A；不能在台上演示未经标定的新抓取目标。

## 4. 出错时怎么做

| 现场现象 | 首先保护 | 排查顺序（优先级从高到低） |
| --- | --- | --- |
| 肩/肘突然快速跳动 | 立即实体断电并承托机械臂 | 是否错误的 `initial_pose`、PWM 脉宽映射、旧租约/上电自动 Home |
| 机械臂突然下垂 | 避让并托住/支撑，不把手伸到运动下方 | 电源供电、PWM OE 状态、承重超载、舵机齿轮、驱动信号是否消失 |
| 夹爪持续嗡鸣/明显升温 | 停任务、按需实体断电，卸载泡沫块 | `close_us` 是否触止挡、夹爪缓冲软垫、超时保护和实际电流 |
| ESP32 频繁重启 | 断开伺服动力并检查供电 | 外部电源不足、线径、接地、同时加速负载、接线松动 |
| I²C 找不到 MPU6050 | 不允许 TELEOP | 供电 3V3、GND、GPIO21/22、WHO_AM_I、AD0 地址 |
| I²C 找不到 PCA9685 | 不允许 ARM | VCC/GND 与上拉、GPIO21/22、0x40 地址扫描、接线质量 |
| Roll/Pitch 颠倒或抖动 | 释放 A，停止移动 | IMU 安装轴、`axis_sign`、中立姿态、滤波与 deadzone、佩戴固定 |
| 按 B 一次爪动作多次 | 释放 A 停止 | 去抖、短按/长按判定、`gripper_event_id` 去重、无线重复包 |
| 设备无线不在线 | robot 应进入 HOLD，不重新 ARM | STA MAC、双方频道一致、ESP-NOW 角色、boot_id、干扰/供电 |
| 浏览器有图、机器人不动 | 不直接临时硬发 PWM | owner/lease、deadman、设备 CALIBRATION 状态、FAULT、权限冲突 |
| 串口 COM 找不到或被占用 | 不启动 REPLAY | USB/CH340、设备管理器 COM、Arduino Monitor、其他 PySerial 进程 |
| 回放开始就被拒绝 | 不绕过 preflight | recording 完整性、校准哈希、起点差、工作区确认、夹爪驻留和限速 |
| 回放动作大幅偏移 | STOP/HOLD，支撑机械臂 | 重播前真实初态是否一致、机械连杆是否松动、时间轴 gap、负载变化 |
| 图表显示掉线 | 不复用上次数据继续运动 | WS/后端状态；只恢复订阅，不自动重启任何控制流程 |

## 5. 安全停止与恢复

### 5.1 普通停止（无立即机械危险）

- 松开手腕 A（TELEOP）或点击 Vue `STOP`（PC_MANUAL/REPLAY）；观察机器人 `state→HOLD`，软件目标不再新增。
- 不主动将全部关节设置为 90°；不以断 PWM 的方式保证“停止”。保持实体结构有安全支撑，明确运动终止后的机械姿态。
- 若发生了超时故障/控制冲突，首先回看事件与本轮 `boot_id/lease`。问题原因不明前拒绝重新 ARM。

### 5.2 紧急断电（机械危险或明显温升）

- **立刻切断外置伺服动力**，确保人不在下落/夹爪范围内，同时使用预先放置的机械支撑。
- 即使 USB 供电还在、电脑仍显示在线，也不能假设机器人能保持夹持姿态；实体断电后软件目标值不再代表真实轴角。
- 重新启动必须从掉电检查开始，重新核对机械初态和安全条件；**不能简单点击“恢复上一轮回放”**。

## 6. 结束后归档与复盘

每次测试结束保留：`recording_id`、`replay_run_id`、一段人工结果说明、失败类型、`firmware_version`、`calibration_id`、`workcell_id`、电源实测信息、对应的测试报告文件。使用英文文件名及路径，对原始轨迹只读保存。

如果抓放失败，优先排查“夹爪夹持力与机械限位、承重电源、起始物体点位、机械臂起点、速度限幅是否与示教一致”，而不是先增加摄像头或引入自然语言控制；这两项**都不属于项目范围**。
