# MotionArm 控制台

先启动本项目 FastAPI 服务，确保 `127.0.0.1:8000` 能访问。在本目录执行：

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。Vite 在本地代理 REST 和 WebSocket，浏览器无需打开串口。软件模拟由后端选择，页面会明确标记。要检查生产构建，运行 `npm run build`。若要用生成的静态文件进行本地预览，运行 `npm run preview` 并打开 `http://127.0.0.1:4173`。

- **总览**显示遥测、设备控制状态、手腕 Roll/Pitch 和四路软件目标。当前位置由同屏读数表达，曲线保留最近 30 秒。
- **手动调试**从标定读取逻辑角度范围，申请独占控制权后可以一次明确提交完整四路目标。页面刷新不会重新申请控制权。
- **示教录制**跟随服务端记录状态，列表可查看采样帧数与保存结果。
- **轨迹回放**可查看四路目标曲线、导出 CSV/JSON、预检后回放。动作入口依赖在线状态、有效校准、后端确认及现场检查。
- **设备标定**是只读配置视图。当前硬件缺少外部关节角度反馈，界面中的角度始终标明是手腕估计或关节软件目标。

断线后连接会自动恢复遥测，运动命令不会自动重发。网页软件停止请求需要设备连接。紧急情况下使用舵机独立动力开关，并按项目硬件说明处理机械臂承重。


若已有package-lock.json，优先用npm ci。当前页面尚未实现Three.js/Remotion 3D；尺寸与装配参考见 [机械臂基线](../docs/Robot_Baseline.md)。
