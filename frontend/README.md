# MotionArm 三维控制台

本地 Vue 3 / TypeScript / Three.js / ECharts 控制台，连接 FastAPI `wearable` 数据源。实时控制只使用真实腕端 IMU，执行端固定为虚拟执行端。没有网页模拟输入或自动演示。

先启动项目 FastAPI 服务（127.0.0.1:8000），然后在本目录执行：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。浏览器通过 FastAPI 读取串口，不能同时用 Arduino 串口监视器占用腕端端口。

1. 选择串口连接，等待静置校准。腕端必须运行 `v:1 / att:3` 完整四元数固件并提供 A/B 点击计数 `ac`、`bc`，旧固件会明确提示不兼容。
2. 松开 A/B 并保持舒适手势静止约 0.5 秒，点击唯一初始化操作 **“启用并回初始”**。这会捕获当前 IMU 手势参考，将虚拟目标设为底座 0°、大臂 45°、小臂 45°、夹爪打开；初始状态为暂停。
3. **短按 A 开始／暂停**。A 固定对应 GPIO25；原始按下／释放指示和“跟随中／已暂停”是两个独立状态。松手不会暂停，也不需要持续按住。
4. Roll 控制底座；Pitch 同向、默认 1:1 协同控制大臂和小臂。跟随以本次启用时捕获的手势为参考，超过默认 5° 软死区的部分按相对角度跟随，固定倾角时目标会停稳。暂停后继续使用同一启用参考，通过输出速度和加速度限制追赶当前手势，不因 A 再次点击而重设参考。
5. **短按 B 切换虚拟夹爪开合**。B 固定对应 GPIO26，仅控制夹爪，不切换臂模式；暂停 A 后夹爪仍保持当前状态。再次点击 B 或重新初始化可改变夹爪状态。
6. 目标超出仿真限位时硬截住，始终保留同一个启用手势参考；退回有效角区后继续跟随，回到启用手势时，三个转轴目标重新映射到 0° / 45° / 45°，输出按限速跟随。达到限位不会平移或重设参考，夹爪仍由 B 独立控制。若提示“大角度姿态有歧义”，回到启用参考附近恢复，不重新设参考。停止、腕端重启或输入失效会禁用控制，必须重新点击“启用并回初始”；不会自动恢复或切换模拟输入。暂停时允许明确重新初始化，跟随、录制或历史回放期间禁止初始化。

三维视图以模拟输出目标驱动真实父子关节层级，可显示请求轮廓、关节坐标和尺寸，支持轨道旋转、缩放及四个视角。WebGL 不可用时保留数值状态台。诊断提示保留固定空间，状态变化不自动适配或重置相机。

录制保存真实 IMU、按钮和虚拟目标，可导出 CSV／JSON、拖动时间轴及进行后端 1 倍速历史回放。历史回放不需要 IMU 在线，与实时控制互斥；缺口不插值，中断数据不能连续自动回放。历史记录保留原来的控制方式和目标数据。

仿真设置仅允许停止后编辑角度软死区、输出速度、加速度和限位。手背安装固定为 X向右、Y从手背指向手肘、Z向下；控制坐标为Roll=−传感器Y、Pitch=+传感器X。关节映射符号按真实佩戴验证固定为底座+1、双臂−1，使右倾时底座俯视顺时针、抬手时双臂抬起；不提供安装或方向配置。所有参数均不代表实机安全标定。

实时遥测仅接受 `schema_version:3`。Roll/Pitch 来自完整四元数相对本次启用参考的旋转向量；未初始化时显示“—”。折叠诊断区提供四元数、参考和三轴角速度／加速度，过期值标为历史接收值。Z旋转不直接驱动底座。初始化门控统一由后端检查完整三维稳定性，参考不保存到配置文件。详见[当前控制台协议与操作](../docs/16_Virtual_Console.md)。

三维姿态始终是 **虚拟关节目标／估算预览**，`measured=null`。末端坐标来自简化几何模型，不是实体位置测量。

```powershell
npm test       # 几何、历史缺口、显示滞回、相机稳定性和点击状态检查
npm run build  # TypeScript 检查和生产构建
npm run preview
```

生产构建本地预览地址为 http://127.0.0.1:4173 ，同样通过 Vite 代理本机 FastAPI。旧 `/manual`、`/teaching`、`/replay` 路径重定向至新工作区。旧后端 mock／serial 模式会被明确标识为不兼容，实时入口锁定。
